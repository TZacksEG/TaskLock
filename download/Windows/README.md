# TaskLock لويندوز

اختار النسخة حسب نوع المعالج:

- [Windows x64 — لمعظم أجهزة Intel وAMD](TaskLock-1.1.0-beta.1-Windows-x64-experimental-beta.zip)
- [Windows ARM64 — لأجهزة Windows on ARM](TaskLock-1.1.0-beta.1-Windows-arm64-experimental-beta.zip)

فك ملف ZIP كاملًا، وبعدها شغّل `Install.cmd` للتثبيت في حسابك، أو `TaskLock.exe` للتجربة المحمولة. النسخة بتضم .NET اللازم ومش محتاجة صلاحية Administrator.

> دي نسخة تجريبية غير موقعة، ولسه ما اتجربتش على جهاز ويندوز فعلي. ابدأ بمعاينة ١٥ ثانية، وما تعتمدش عليها قبل ما تراجع [قائمة اختبار ويندوز](../../docs/Windows-testing.md).
